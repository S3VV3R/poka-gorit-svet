# Проверка v1.1.3 — 22 октября 2026

Проверки используют искусственные данные и не читают сохранения игрока.
Итог: общий набор автоматических проверок завершён успешно, включая новые тесты.

## Новые проверки

- Чтение старого формата, заполнение недостающих полей и запись нового формата.
- Независимость трёх слотов от автосохранения; копия при перезаписи слота.
- Отказ записи при заполненной памяти: текущая игра и основное сохранение остаются.
- Восстановление предыдущего автосохранения при повреждении основного.
- 15 некорректных импортов: повреждённый JSON, чужой формат, неверные разделы,
  опасные ключи объекта, чрезмерный размер, недопустимые изображения и даты.
- Скачивание и обратное чтение JSON; импорт в отдельный слот без запуска игры.
- Закрытие окна во время чтения файла не открывает его повторно после завершения.
- Подтверждение новой игры, отмена, ошибка записи и успешное продолжение.
- Escape отменяет подтверждение, не возобновляя игру под ним.
- Звук и текст сохраняются независимо от сюжетного прогресса; применяются после загрузки.
- Обучение отмечает пройденные действия, не реагирует на сценарное движение,
  не записывает состояние каждый кадр и скрывается при диалогах/меню.
- Старая игра после знакомства не получает повторного обучения автоматически.
- Первая игра запускается и при запрете хранилища, с предупреждением об ошибке записи.
- Загрузка ручной контрольной точки из паузы проверяется на настоящем движке Phaser
  в headless-режиме: старые сцены остановлены, квартира и камера работают, затемнения нет.

## Регрессии

Общий запуск: `node tools/test.cjs`. Для теста движка нужен `@napi-rs/canvas`;
самой игре и GitHub Pages зависимости Node.js не нужны.

Также проверяются постепенные диалоги без пропуска, переход с балкона в главу 2,
движение при 30/60 кадрах, поворот экрана, управление касаниями, меню занятий,
120 действий, 120 ветвей решений, 120 ветвей событий, доступность мебели,
жизнь семьи и загрузка ресурсов из корня сайта и вложенной папки репозитория.

## Ограничения проверки

Для новых окон выполнены проверки логики на имитации DOM, но не визуальная проверка
в живом браузере: инструмент управления браузером в этой сессии недоступен.
На реальных Android/iOS ещё нужно проверить системный выбор файла, скачивание JSON,
длинные меню при большом шрифте, экранные вырезы и доступность с экранным диктором.
Настоящее заполнение памяти разных браузеров также не воспроизводилось: использован
контролируемый отказ записи. Нельзя считать это гарантией для любого устройства.

Локальное хранилище ограничено браузером; фотографии и резервные копии расходуют его.
Рекомендуется скачивать важные сохранения. GitHub Pages-публикация не выполнялась.
