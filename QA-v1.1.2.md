# Проверка v1.1.2 — 22 октября 2026

## Автоматические проверки

- Профили iPhone, Android, iPad (в том числе desktop UA), Windows с сенсорным экраном,
  узкое окно без сенсора, неизвестные сведения о памяти/процессоре.
- Поворот телефона сохраняет тип устройства; большой вертикальный планшет тоже
  получает предупреждение. Узкое окно компьютера не блокируется.
- Запуск только один раз, пауза/возобновление при поворотах, сцена, закончившая
  загрузку за предупреждением, не продолжает работать в вертикальном положении.
- Расчёт кадров для экранов 59,94 / 60 / 90 / 120 / 144 Гц при лимитах 30 и 60.
  При чередовании интервалов 16,4 и 16,8 мс старый алгоритм выдаёт 300 кадров
  за 600 вызовов, новый — не менее 597. Это синтетический тест расчёта, не замер
  производительности реального телефона.
- Одинаковое расстояние движения за секунду при 30/60 кадрах, включая настоящий
  Phaser; длинная остановка не передаёт физике многосекундный шаг.
- Автоматическое понижение нагрузки двумя ступенями, отсутствие колебаний качества,
  исключение меню/фона/поворота/паузы загрузки, ручной режим и повторная проверка.
- Облегчение и восстановление декоративных частиц без удаления персонажей.
- Общий набор проверок сюжета, диалогов без пропуска, сохранений, перехода
  с балкона во вторую главу, домашних взаимодействий, относительных путей GitHub Pages.

## Границы проверки

Тип устройства — приблизительная классификация по возможностям браузера и его
описанию, а не достоверное определение конкретной модели. Объём памяти браузер
может округлять или скрывать. Реальные iPhone/Android и длительное нагревание
устройства в этой среде не проверялись; одинаковые 60 кадров везде не гарантируются.

## Проверка в браузере

Встроенный Chromium, окно 1280×720: загрузка, новая игра, пауза, возврат в меню,
диагностика устройства и графики WebGL, ручной экономный режим и повторная
автоматическая проверка работают. После игры диагностика показала 60 кадров/с.
Ошибок и предупреждений в консоли при этой проверке не было.

Окно 390×844 без сенсорного ввода правильно осталось компьютером: предупреждение
о повороте скрыто, горизонтального переполнения страницы нет. Это не эмуляция телефона.
Тестовый размер окна сброшен после проверки. Изображение результата сохранено
рядом с архивом: `v1.1.2-device-check.jpg`.
