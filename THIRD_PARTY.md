# Сторонние компоненты

`vendor/phaser.min.js` — Phaser 3.90.0, движок из исходной версии игры.
Его MIT-лицензия сохранена в `vendor/LICENSE.txt`.
Источник лицензии: https://github.com/phaserjs/phaser/blob/v3.90.0/LICENSE.md

`@napi-rs/canvas` используется только необязательными локальными тестами,
устанавливается отдельно через npm и не загружается сайтом.

Лицензия Phaser не распространяется автоматически на авторский сюжет,
изображения и собственный код игры. Новая лицензия для них не назначалась.
